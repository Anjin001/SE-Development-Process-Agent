# 任务分解模块交付（乔璐脉）

分支：feat/task-planner。实现入口：se_agent/planner.py。

保留 v1 decompose(spec)，新增 v2 decompose_tasks(confirmed_spec) 和 export_plan(plan, directory)。不修改 contracts.py、server.py 和编排模块。公共契约无字段变动。

分解以结构化决策中的 requirement_ids 为工作单元：准备规则 → 各需求实现与说明文档并行 → 集成验收。每项任务保留需求、决策、完成条件、路径、输出、估时和审核开关。未决项仅挂在对应需求的实现任务，准备任务及独立说明任务不受阻塞。是否阻塞由编排器根据 OpenItem.blocking 与 resolution 判断。

当前为确定性规划基线，无模型调用。估时为课堂演示的模板估计（准备和文档300秒、实现600秒、集成300秒），实际启动前需负责人核对。自动分配 app/task_N.py 是建议路径，编排计划编辑时应按目标仓库真实模块调整。任务正文保留已确认规则，不能将未决项擅自解释成业务决策。

export_plan 接收编排服务已组装、校验的完整 Plan，不分配版本和基线。workflow.json 保存完整 Plan，task.md 从同一快照生成所有任务字段；编辑后的估时、依赖、审核设置均随导出保留。DAG、路径校验、状态、排期与 SQLite 均由编排模块负责。
