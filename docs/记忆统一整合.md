# 记忆实现统一：整合交付

## 最终职责

整合分支 integration/memory-unification 合并 QLM 和 ZXQ。Store 负责连接、线程锁、事务和运行数据；Store.memory 是领域记忆唯一业务入口。DomainMemory(store=store) 不拥有连接，close 不关闭 Store。旧 DomainMemory(path) 仅保留独立数据库兼容用途，项目运行、浏览器和演示统一使用 Store。

Store.tx 支持嵌套保存点：内部失败回滚到保存点；外部失败连同业务和记忆一起回滚。共享连接的记忆读写都获取 Store 的 RLock，防止其他线程在同一连接上混入业务事务。必须在事务外构造 Store/DomainMemory，初始化建表不能在业务事务中调用。

## 已接入的业务链

Store.save_spec 将确认规格、决策、未决项与项目内可见的记忆交接产物、阶段 checkpoint 在同一事务提交。checkpoint 标记 pending planning。若外层失败，两者均不保存。记忆产物 ID 包含项目与版本，防止跨项目重名。规格记录由可信服务提供 confirmed_by，不能接受未经认证的外部操作者。

浏览器 memory_server 与生命周期演示 memory_demo 已切换为 Store.memory。旧 Memory(store) 是兼容门面，绑定 project_id、agent_id、stage 后调用同一服务，不再读写 experiences 表。未绑定身份的历史搜索、跨项目调用、调用者伪造阶段与直接发布均失败关闭；需使用服务端审核入口 publish。

旧 API register_agent/join_project/add_case/alias/usages 等不再作为隐式管理接口保留，调用方迁移到领域服务的 join/save/alias 或统一服务端管理接口。仓库代码搜索表明旧 Memory 仅在测试中被使用，没有现行业务调用者。原测试中允许悬空来源和匿名访问的假设被新安全边界测试替代；检索、版本、别名与使用记录的场景继续由 test_domain_memory 覆盖。

## 迁移

先停止旧服务写入，执行：

```bash
python -m se_agent.memory_migration --db se_agent.db --backup se_agent.before-memory.sqlite
```

必须使用新的备份文件名，CLI 拒绝覆盖。迁移先用 SQLite backup 生成一致性备份，再在事务中：

1. 将旧 agents/project_members/project_cases/experiences/tags/keywords/aliases/sources/usage/messages/issues/checkpoints 的所有行复制到 dm_legacy_archive。
2. 为每个经验版本写 dm_legacy_map，保留旧 ID/版本并记录新 ID/版本；若与现有 QLM ID 冲突，分配独立 ID，后续版本沿用映射。
3. 旧经验来源权限缺失，全部作为私有待复查记录导入，不自动成为可公开推荐的经验；原来源完整保存在 legacy_sources 和归档中。
4. 在旧记忆表建立拒绝 INSERT/UPDATE/DELETE 的触发器，防止旧服务重新成为第二套事实来源。保留旧表与归档供核对，不删除旧数据。

重复迁移不重复导入经验。复查时管理员在统一库重建真实来源记录，审核人员核对证据与权限后建立可发布的经验版本和新项目基线。迁移报告明确给出隔离数量；不能把迁移完成等同于所有旧经验已审核放行。历史使用日志原样归档，不伪造当前身份或凭证。

如需撤回迁移，停止服务，保留失败库供排查，用备份恢复整个数据库，再部署旧程序；不要只删除映射表或单独恢复经验表。未在本次任务中操作任何真实业务数据库。

## 复现与验证

```bash
python -m unittest discover -s tests -v
python -m se_agent.memory_demo
```

test_memory 覆盖共享连接、外层原子回滚、嵌套保存点、关闭所有权、旧接口身份隔离、版本迁移重复执行、旧写入阻断，以及真实 save_spec 和记忆同步事务。其余 ZXQ 计划、运行、审核、租约和事件测试全部保留。

## 合并范围

本分支只承担 QLM/ZXQ 记忆与存储统一；不直接改写 CLY 赛马/评审预览，不合入 Hza 与 ZXQ 同名 worker.py 的执行差异，不把独立模块测试解释为全项目真实模型端到端验收。后续由组长把 CLY 确认入口连接 Store.save_spec，统一认证后构造 MemorySession。原始底层 save/join 等仍是可信控制器管理接口，不可注册成 Agent 自由工具。

最终验收：125 项完整测试通过；memory_demo 使用 Store.memory 的生命周期演示通过；git diff --check 通过。远端 fetch 两次连接失败，本整合基于已获取的 QLM 19c92d9 和本地 origin/ZXQ 快照，上传前未能刷新远端。
